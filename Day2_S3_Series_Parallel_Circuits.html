⚡ Short Circuit（短路）必考

当一根低电阻导线直接接在元件（如灯泡）两端：

  • 电流全部走导线（因为电阻极小）
  • 灯泡熄灭（没有电流通过）
  • 电流急剧增大 → 可能引起火灾
⚠️ 考试答案模板：
A short circuit happens when a wire of very low resistance is connected across a component. This provides an easier path for the current, so nearly all current flows through the wire instead. It is dangerous because the large current can cause a fire.

✏️ 英文题目

Q1: What is the main difference between a series circuit and a parallel circuit?
In a series circuit, components are connected one after another. In a parallel circuit, components are connected across separate branches.
Q2: What happens to the current in a series circuit?
The current is the same everywhere in a series circuit.
Q3: What happens to the current in a parallel circuit?
The current in the main loop equals the sum of the currents in all branches.
Q4: In a series circuit with two bulbs, what happens when one bulb is removed?
The circuit becomes open, and both bulbs go out.
Q5: What is a short circuit and why is it dangerous?
A short circuit occurs when a low-resistance wire is connected across a component. It causes a very large current, which can cause a fire.

📘 Assignment Book 真题 — 8.6 Series & Parallel

以下题目来自 Assignment Book 2A。

📝 True or False: In a series circuit, the current is the same at every point.
True.
📝 True or False: In a parallel circuit, if one bulb blows, all bulbs go out.
False. Only in a series circuit.
📝 MC: Which is correct about a parallel circuit?
Voltage is the same across each branch; current splits.
📝 MC: Three bulbs are connected in series. One is removed. What happens?
All bulbs go out (circuit is broken).
📝 Explain what a short circuit is and why it is dangerous.
A low-resistance wire across a component allows too much current, which can cause fire.
